* Achieved ~85% test accuracy

* TensorFlow / Keras
* Pandas

## 3. IMDb Movie Review Sentiment Analysis

A Recurrent Neural Network (RNN) model for sentiment analysis on movie reviews from the IMDb dataset.

### Highlights

* Natural Language Processing (NLP) project
* Word embedding representation using Keras Embedding layer
* Sequence preprocessing with padding
* Simple Recurrent Neural Network (SimpleRNN) architecture
* Binary sentiment classification (Positive / Negative reviews)
* Achieved competitive accuracy on the IMDb benchmark dataset

### Dataset

IMDb Movie Reviews Dataset (Keras Datasets)

### Tech Used

* Python
* TensorFlow / Keras
* NumPy
* SimpleRNN
* Embedding Layers
* NLP Preprocessing

### Model Architecture

* Embedding Layer (10,000 vocabulary size)
* SimpleRNN Layer
* Dense Output Layer with Sigmoid Activation

### Learning Outcomes

* Text preprocessing and tokenization
* Sequence padding for variable-length inputs
* Word embeddings for text representation
* Understanding recurrent neural networks
* Sentiment analysis using deep learning
